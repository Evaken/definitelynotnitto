# Pixel-art workshop scenes

These plates are original generated game assets. They deliberately contain no
cars, people, UI, logos or text. The live `VehiclePortrait` renderer supplies
the selected owned car and its saved body colour.

- `garage-bay-v1.webp`: empty midnight tuner workshop with an open parking bay.
- `modification-hoist-v1.webp`: matching workshop with an empty two-post hoist.

Both were generated with the built-in image-generation workflow from prompts
requesting wide, car-free 16/32-bit arcade-pixel workshop environments with
clear central composition zones. Hoist contact arms are supplemented by a
small code-native foreground layer so they remain visually attached to the
runtime vehicle.
